2. Кнопки / CTA выбрано B-B

Для «Обсудить проект», «Начать проект», secondary Telegram.

B-A Rect outline

Прямоугольник без скруглений (как LET’S GO на скрине 5). Hover заливает белым.

B-B Arrow orb

Как на скрине 6: текст + круг со стрелкой. Меньше «кнопка», больше жест перехода.

B-C Cut corner fill

Срезанный угол, синяя заливка — tech/UI акцент без pill.

B-D Text underline

Для вторичных действий и ссылок в кейсах: без рамки, только линия и стрелка.

3. Форма «Обсудить проект» выбрано F-B

Те же поля (задача / ТЗ / контакт), другая оболочка.

F-A Soft panel

Лёгкая панель со скруглением — ближе к текущему модалу, но чище.

F-B Underline fields

Без коробок у инпутов: только нижняя линия. Максимально editorial / digital.

F-C Signal strip

Акцентная полоса слева + срезанная CTA. Ощущение «системной» формы.

7. Плавающий значок

Не «синий чат», а digital-объект. Наведи на превью.

I-A Radar signal

Пульс «на связи»: кольца расходятся от точки. Живой статус, не иконка мессенджера.

I-B Status dock
Написать ↗

Компактный док: зелёная точка → при hover раскрывается подпись. Как system tray.

I-C Code brackets
</>PING

Скобки бренда как кнопка. На hover разъезжаются, появляется PING.

I-D Magnet expand
↗Обсудить

Сначала только orb со стрелкой, при наведении — выезжает слово. Жест «открой контакт».

I-E Mini terminal
>_

Мини-терминал с курсором. Атмосфера «разработчик на связи», без шаблонного чата.

8. Скролл ↔ видео и hover секций

Как робот реагирует на скролл + как ведут себя блоки при наведении.

M-A Frame lock
кадр = позиция скролла

Жёсткая связь скролл→кадр. Максимальный контроль, почти без инерции.

M-B Layer parallax
видео / veil / glow — разные скорости

Слои едут с разной скоростью: глубина без «лага» основного кадра.

M-C Section magnets
якоря: герой → кейсы → FAQ

Прогресс «липнет» к ключевым секциям — ощущение глав, а не бесконечной ленты.

M-D Rubber settle
лёгкий overshoot и усадка

Чуть перелетает цель и мягко садится. Живее, чем линейный scrub.

Hov-A Edge reveal
Наведи · кейс / услуга

Слева вырастает сигнальная полоска, текст чуть сдвигается. Без «прыжка» карточки.

Hov-B Text wipe
Похожий кейс

Текст уезжает вверх, снизу въезжает действие. Сильный digital-жест.

Hov-C Index tick
06Похожие проекты

Номер секции «щёлкает» и подсвечивается — ощущение каталога/системы.

9. Анимации кнопок

Для «Обсудить проект» / orb-кнопок. Наведи на каждый вариант.

Btn-A Orb fill + twist

Круг заливается белым, стрелка чуть поворачивается. База под B-B, но с характером.

Btn-B Underline draw

Линия прорисовывается под текстом, orb уезжает вправо. Editorial / digital.

Btn-C Label swap

Два состояния текста: основное → при hover второе. Без смены формы кнопки.

Btn-D Scan sweep

Горизонтальный «скан» по кнопке — для submit в формах.

Btn-E Magnetic nudge

Orb чуть «дрожит» к курсору. Живой акцент в шапке / CTA.
