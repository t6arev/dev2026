# Этап 5: SEO-рост и выход в топ по ключевым запросам

> **Когда начинаем:** после завершения главной страницы (дизайн, кейсы с фото, формы, деплой на dev2026.ru).  
> **Цель этапа:** не «красивая разметка», а **органический трафик** по запросам вроде «разработка telegram ботов», «заказать тг бота», «mini app telegram» и нишевым long-tail.

---

## Что уже сделано (техническая база — этап 4)

Это **фундамент**, без него дальше не строить. Но само по себе **не поднимает в топ**.

| Сделано | Файл / где | Что даёт |
|--------|------------|----------|
| Title, description, keywords | `index.html` | Текст сниппета в выдаче |
| Open Graph + Twitter Card | `index.html` | Превью при шаринге ссылки |
| Canonical URL | `index.html` | Один главный URL в индексе |
| Favicon + apple-touch-icon | `assets/brand/logo.png` | Иконка рядом с ссылкой в Google/Яндекс |
| JSON-LD Person | `index.html` | Подсказка «кто вы» для поисковика |
| robots.txt | корень | Разрешение индексации + ссылка на sitemap |
| sitemap.xml | корень | Карта сайта для вебмастеров |
| site.webmanifest | корень | Иконки для PWA / «Добавить на экран» |
| Яндекс.Метрика | `js/analytics.js` | Аналитика поведения и конверсий |

**Ожидание:** красивый сниппет, иконка, нормальная индексация главной.  
**Не ожидать:** рост позиций по конкурентным ключам только от этого.

## Почему одной главной мало

Поисковики ранжируют **отдельные страницы**, а не «сайт целиком».

Запрос «разработка telegram ботов» конкурирует со студиями, агрегаторами (FL.ru, Kwork), статьями на Habr. Одна лендинг-страница с блоками «услуги / кейсы / цены» — слабый кандидат на топ.

**Стратегия:** главная = бренд + обзор; **отдельные посадочные** = конкретные ключи; **блог** = длинные запросы и экспертность.

## Блок 1. Посадочные страницы (приоритет №1)

Создать отдельные URL под услуги. Каждая — самостоятельная SEO-страница.

| URL (пример) | H1 | Основной ключ |
|--------------|-----|---------------|
| `/telegram-boty/` | Разработка Telegram-ботов под ключ | разработка telegram ботов |
| `/mini-apps/` | Telegram Mini Apps — разработка и запуск | mini app telegram |
| `/ai-boty/` | AI-боты и ассистенты в Telegram | ai бот telegram |
| `/sayty/` | Сайты и лендинги для бизнеса | разработка лендинга |
| `/kastom/` | Кастомные решения и автоматизация | автоматизация бизнеса telegram |

### Структура каждой посадочной (шаблон)

1. **Hero:** H1 с ключом + оффер + CTA «Обсудить проект»
2. **Для кого:** 3–4 сценария (салон, доставка, e-commerce, SaaS)
3. **Что входит:** этапы, сроки, стек
4. **Цены:** вилка или «от X ₽» (как на главной, но под услугу)
5. **Кейсы:** 2–3 релевантных из портфолио с **текстом** (задача → решение → результат)
6. **FAQ:** 5–7 вопросов с ключами («Сколько стоит telegram-бот?», «Какие сроки?»)
7. **Форма заявки** + ссылка на Telegram
8. **Внутренние ссылки:** на главную, другие услуги, блог

### Объём текста

- Минимум **800–1500 слов** уникального текста на страницу
- Не копипаст с главной — переформулировать под запрос
- Ключ в H1, 1–2 раза в первом абзаце, в подзаголовках H2/H3 естественно

### SEO на каждой странице

```html
<title>Разработка Telegram-ботов под ключ | цены, сроки, кейсы — dev2026.ru</title>
<meta name="description" content="...150–160 символов с ключом и оффером...">
<link rel="canonical" href="https://dev2026.ru/telegram-boty/">
<meta property="og:image" content="https://dev2026.ru/assets/brand/logo.png">
```

+ JSON-LD `Service` или `ProfessionalService`  
+ JSON-LD `FAQPage` для блока FAQ  
+ Добавить URL в `sitemap.xml`

## Блок 6. Реклама как ускоритель (этап 4 roadmap, но связан с SEO)

SEO — месяцы. Реклама — дни. Использовать **параллельно**, не вместо.

### Яндекс.Директ / Google Ads

- Старт с long-tail: «бот для записи клиентов», «mini app telegram заказать»
- Посадочная = **узкая страница услуги**, не главная
- UTM + цель Метрики `lead_submit`
- Бюджет тест: от 5–10 тыс. ₽/нед, 2 недели, смотреть CPA

### Связь с SEO

- Реклама даёт трафик → поведенческие сигналы → косвенно помогает SEO
- Запросы из Директа с хорошей конверсией → темы для статей и посадочных

## Пакет «800 запросов» у SEO-компаний — что это

Обычно **не** «800 посетителей», а одно из:

1. **Семантическое ядро** — список ~800 поисковых фраз (ВЧ / СЧ / НЧ).
2. **Контент-план** — тексты и страницы под часть этих фраз.
3. **Отчётность** — «продвигаем N запросов» (позиции в топ-10/20/30).

### Как применить у себя без агентства

1. Собрать **50–100 запросов** (Wordstat, Keys.so, Serpstat или вручную).
2. Разбить на группы:
   - **коммерческие** → посадочные (`/telegram-boty/`, `/ai-boty/` …)
   - **информационные** → статьи в блог
   - **нишевые long-tail** → «бот для салона», «бот для доставки»
3. На каждую группу — **отдельная страница**, **800–1500+ слов** уникального текста.
4. Через 2–3 мес. смотреть **Вебмастер / GSC → поисковые запросы** и допиливать title/description по запросам с показами без кликов.

**Пакет 800 запросов имеет смысл только вместе со страницами под них.** Без контента — это Excel, не трафик.

### Покупать ли SEO-пакет

Имеет смысл, если агентство даёт **реальные кейсы в нише**, **страницы + тексты**, не обещает топ за месяц по ВЧ и **не** продаёт тысячи ссылок с бирж.

Дешевле на старте: **4 посадочные + 6 статей** по своему ядру — сильнее абстрактного «800 запросов» без контента.
